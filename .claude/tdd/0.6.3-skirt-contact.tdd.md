## Known gap

The test harness is pure .NET and cannot visually simulate the user's exact
modded garment inside Unity. Runtime scan summaries therefore record the
top/bottom DynamicBone component and root names once per clothing change. No
coverage collector is configured for this net35 console harness, so no coverage
percentage is claimed.
